# Security policy

For security concerns, avoid posting secrets or sensitive dataset content in
public issues. Contact the repository maintainer through a private GitHub
security advisory if the repository enables that functionality.

This tool operates on local files. Review inputs before passing source URLs or
identifiers that might contain secrets. File provenance is self-declared and is
not equivalent to cryptographic source attestation.

Supported versions: the most recent tagged release (once one exists); until
then, development on `main` is provided as-is.

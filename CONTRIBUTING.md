# Contributing

Thanks for your interest. Contributions should improve reusable, general-purpose
data validation, provenance and reproducibility workflows.

1. Open an issue describing the problem and reproducible expected behavior.
2. Make a small change with standalone unit tests using **synthetic data**.
3. Run `python -m pip install -e '.[dev]'` and `python -m pytest -q`.
4. Document any changed CLI/API behavior and compatibility impact.
5. Submit a pull request; maintainers review compatibility and safety.

Do not submit proprietary formulas, copyrighted datasets without explicit rights,
access credentials, nonpublic model code or confidential provider inventories.
By contributing, you agree that your contribution may be distributed under MIT.

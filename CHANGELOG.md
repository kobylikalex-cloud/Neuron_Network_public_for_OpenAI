# Changelog

## 0.1.0 — Initial release candidate (unpublished)

- Added CSV time-series validation for ISO dates, decimal values, duplicate
  timestamps, chronological ordering and basic calendar-frequency gaps.
- Added SHA-256 raw-file checksums and file verification.
- Added JSON provenance sidecars with source URL, dataset ID, retrieval date,
  file size, filename and checksum.
- Added atomic JSON writing, an installable CLI and synthetic example data.
- Added Python CI test workflow and standalone tests.

This release is an initial software utility, not a scientific verification of
any source data and not a financial product. Publication is pending maintainer
approval and review of the proposed MIT license.
